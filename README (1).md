# Week 2 - Supervised Machine Learning Models

## Models
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

## Datasets
- Diabetes dataset from scikit-learn for Linear Regression.
- Breast Cancer dataset from scikit-learn for classification.

## Run
```bash
pip install numpy pandas matplotlib scikit-learn
python week2_supervised_ml.py
```

The program saves predictions, confusion matrices, CSV results, and charts in
the `outputs` folder.
